اقترح مبادرة

بعد الإرسال، لن تظهر للناس حتى يراجعها المشرف ويوافق عليها.

لا تضع أرقام هواتف أو عناوين منزلية أو بيانات حساسة في الوصف. هذا النموذج يرسل الاقتراح إلى قاعدة البيانات بعد إعداد الإعدادات أدناه.

لوحة المشرف

تسجيل دخول آمن لمراجعة الاقتراحات وقبولها أو رفضها.

لا تضع كلمة مرور المشرف داخل كود HTML. أنشئ حساب المشرف في Supabase Auth وأضف بريده إلى جدول المشرفين حسب ملف التعليمات.
لا توجد طلبات محمّلة.
يجب إعداد Supabase قبل استخدام إرسال المبادرات أو لوحة المشرف.
